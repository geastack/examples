# Quaternius Ultimate Spaceships

Source: https://quaternius.com/packs/ultimatespaceships.html
License: CC0 1.0 Universal

Files used by this example:

- `player-spitfire.gltf` from the Spitfire glTF folder.
- `enemy-striker.gltf` from the Striker glTF folder.
- `player-spitfire-blue.png` from `Spitfire_Blue.png`.
- `boss-spitfire-red.png` from `Spitfire_Red.png`.
- `enemy-striker-red.png` from `Striker_Red.png`.

The glTF files and texture variations are checked in so the iOS example can bake
textured vertex colors without a network dependency.
