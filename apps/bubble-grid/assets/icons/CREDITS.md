# Icon sources

Each icon is the `AppIcon` asset the application itself ships in its own
repository — full-bleed artwork designed to be masked by the OS, so the
circular tile is the app's own icon with its own background, not a synthesised
one. Six come from the project's watchOS target. All source projects are open
source; see each repository for its licence.
